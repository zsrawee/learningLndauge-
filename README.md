# voice-tutor

تسجيل صوتي يشرح مقطع بلغتك بلغتك — بالعربي، بالإنجليزية، بأي لغة.

## الفكرة
ترفع مقطع صوتي، التسجيل يقرأه، يجد الجمل الصعبة على مستوى المبتدئ، ويرجع لك ملفاً معدّلاً: يقطع المتحدث ويدخل شرحاً مسموعاً بدلاً منه، ثم يكمّل. ما له دخلة — المستخدم بس يستني الملف الجاهز.

## البنية
- Node 22 + Express (UI + API)
- Whisper (faster-whisper) للتحويل للنص
- edge-tts للصوت المجاني (محدود المعدل)
- فهم خارجي (relay API) للتحليل

## الخصائص
- مستوى + كثافة — ثلاث حقول للمستخدم: ماذا يبي، ماذا ما يبي، أسئلة دقيقة
- وضع مرن / ثابت — الأسئلة الثابتة تنتقل للتحليل
- استئناف تلقائي — لو انقطعت، يكمل من آخر ما سجّل
- التفريغ الصوتي — على الجهاز مباشرة

## الملاحظات
- data/secrets.json مفتاح الـ API (مفقود من المستودع)
- دليل الأوزان .models مفقود من المستودع
- بيانات التشغيل (logs, output, work) مفقودة من المستودع
